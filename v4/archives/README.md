# V4 archives

4 standalone .NET 8 examples using Aspose.Email 26.10.0. This is part of the [partial V4 delivery](../README.md); read [V4 agent guidance](../AGENTS.md) and the [manifest](../manifest.json) for hashes and validation scope.

- [95699.cs](95699.cs): Load messages from "LegalMails" directory using a local GetMessages iterator and add them to "Legal" folder.
- [95799.cs](95799.cs): Retrieve only subject and date fields using EnumerateMessageInfo and write them to a summary text file.
- [95805.cs](95805.cs): Create a MailMessage with To, Cc, and Bcc fields and store it in Messages.mbox.
- [95837.cs](95837.cs): Append a MailMessage with IsDraft set to false to an existing MBOX file to ensure draft restriction compliance.
