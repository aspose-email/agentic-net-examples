# V4 calendar

5 standalone .NET 8 examples using Aspose.Email 26.10.0. This is part of the [partial V4 delivery](../README.md); read [V4 agent guidance](../AGENTS.md) and the [manifest](../manifest.json) for hashes and validation scope.

- [95552.cs](95552.cs): Create a new appointment with HTML description and save it as a .msg file using AppointmentMsgSaveOptions.
- [95562.cs](95562.cs): Collect a set of appointment objects and write them all to one .ics file using CalendarWriter.
- [95584.cs](95584.cs): Use CalendarWriter to write a collection of appointments that include display and audio reminders to a .ics file.
- [95608.cs](95608.cs): Load a local MSG meeting as MapiCalendar, add attendees with MapiRecipientCollection and MapiRecipientType.MAPI_TO, and save the updated MSG.
- [95610.cs](95610.cs): Load a local MSG meeting as MapiCalendar and save it as ICS with default options.
