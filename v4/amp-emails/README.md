# V4 amp-emails

6 standalone .NET 8 examples using Aspose.Email 26.10.0. This is part of the [partial V4 delivery](../README.md); read [V4 agent guidance](../AGENTS.md) and the [manifest](../manifest.json) for hashes and validation scope.

- [95676.cs](95676.cs): Instantiate AmpMessage, set HtmlBody with style block, add AmpAccordion with three panels, save as amp_styled_accordion.eml.
- [95679.cs](95679.cs): Instantiate AmpMessage, set HtmlBody with meta viewport tag, add AmpFitText component, save as amp_viewport_fittext.eml.
- [95681.cs](95681.cs): Create AmpForm with submit button labeled Subscribe, method POST, add to message, save as amp_form_subscribe.eml.
- [95683.cs](95683.cs): Create AmpMessage, add AmpCarousel with three images, then add AmpForm below carousel, save as amp_carousel_form.eml.
- [95685.cs](95685.cs): Instantiate AmpMessage, set HtmlBody with header element, add AmpAccordion with two panels, save as amp_header_accordion.eml.
- [95686.cs](95686.cs): Create AmpForm with CSRF token hidden field, email text field, and submit button, save as amp_form_csrf.eml.
